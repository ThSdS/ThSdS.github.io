# ThSdS.github.io

Página pessoal de ferramentas, publicada em https://thsds.github.io.

- `/` hub das ferramentas
- `/coleta-dje/` página da aplicação usada pelo rclone (Google Drive)
- `/privacidade/` política de privacidade
- `/termos/` termos de uso

Para acrescentar uma extensão: criar a pasta `/<nome>/index.html` com o mesmo cabeçalho e rodapé e incluir um cartão em `index.html`.
