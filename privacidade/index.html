Política de privacidade

Última atualização: 18 de novembro de 2026.

Esta política vale para as ferramentas publicadas neste site e é regida pela Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018). Responsável e contato: thalissonsilva+git@gmail.com.

1. Quem usa

As ferramentas são de uso pessoal do autor. Não há cadastro, conta, venda, publicidade nem coleta de dados de terceiros.

2. Coleta DJE e dados do Google

A Coleta DJE acessa a conta Google do próprio autor, mediante autorização dada por ele, para gravar, listar e atualizar arquivos numa pasta do Google Drive reservada à coleta. Os dados tratados são esses arquivos, gerados a partir de publicações oficiais do Diário da Justiça Eletrônico do TJRS, que já são públicas.

  • Acesso: somente à conta que autorizou a aplicação e somente para as operações descritas acima.
  • Armazenamento: o token de acesso fica apenas na máquina virtual do autor, em arquivo de configuração protegido. Não há banco de dados nem cópia em serviço de terceiros.
  • Compartilhamento: nenhum dado obtido das APIs do Google é vendido, cedido ou transferido a terceiros, nem usado para publicidade ou para treinar modelos de inteligência artificial.
  • Exclusão: a autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions; com isso o acesso cessa de imediato.

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

3. Extensões de navegador

Cada extensão descreve na própria página os dados que lê e onde os guarda. Salvo indicação em contrário, os dados ficam no navegador de quem a usa e não são enviados ao autor.

4. Direitos do titular

Pedidos de confirmação, acesso, correção ou eliminação de dados (Lei nº 13.709/2018, art. 18) podem ser feitos pelo e-mail acima.

English summary

These are personal tools of the author. The Coleta DJE app accesses only the author's own Google Drive, with his consent, to upload, list and update files in a single folder. Google user data is not sold, shared, used for advertising or used to train AI models. The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
